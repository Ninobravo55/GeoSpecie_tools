## Español 🇪🇸

**GeoSpecies Tools** es un plugin para QGIS diseñado para facilitar la descarga de variables ambientales (como WorldClim y SoilGrids) mediante Google Earth Engine (GEE), así como proporcionar herramientas útiles para la preparación de datos orientados al modelamiento de especies (por ejemplo, con MaxEnt).

### Características Principales
*   🌍 **Descarga con GEE:** Acceso rápido a variables climáticas y de suelo globales (WorldClim, SoilGrids).
*   📊 **Preparación de Datos:** Herramientas específicas para adecuar registros de especies y variables para algoritmos como MaxEnt.
*   ⚡ **Integración en QGIS:** Flujo de trabajo directo desde tu entorno SIG.

---

## English 🇬🇧

**GeoSpecies Tools** is a QGIS plugin providing Google Earth Engine (GEE) tools for downloading environmental variables (such as WorldClim and SoilGrids) and utilities for species data preparation for ecological niche modeling (e.g., MaxEnt).

### Key Features
*   🌍 **GEE Downloading:** Quick access to global climate and soil variables (WorldClim, SoilGrids).
*   📊 **Data Preparation:** Specific tools to prepare species occurrence records and environmental layers for algorithms like MaxEnt.
*   ⚡ **QGIS Integration:** Direct workflow from within your GIS environment.

## 🛠 Instalación / Installation

1. Descarga el archivo `.zip` de la última versión desde el repositorio oficial de plugins de QGIS.
2. En QGIS, ve a **Complementos > Administrar e Instalar Complementos...** (*Plugins > Manage and Install Plugins...*).
3. Selecciona la pestaña **Instalar a partir de un archivo ZIP** (*Install from ZIP*), busca el archivo descargado y haz clic en **Instalar complemento** (o búscalo directamente en la pestaña "Todos" si ya está aprobado).
